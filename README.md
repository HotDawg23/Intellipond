# IntelliPond

IntelliPond is a web system for monitoring pond water quality, recording Bangus growth, tracking alerts, and reviewing pond reports.

For the end-to-end architecture, user roles, data flow, calculations, model scope, and known implementation limits, see the [System Overview](docs/system-overview.md).

The growth model, its data sources, training process, and evaluation are documented separately in [ml/README.md](ml/README.md).
